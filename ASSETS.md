# Coin Journal visual assets

Created for this project on 2026-10-02. No templates, commercial app copies, downloaded illustrations, paid fonts, stock imagery or model API calls were used.

- `icons/mark.svg`: original T/J monogram, hand-authored SVG paths and circle.
- `icons/sol.svg`: original layered arc glyph for the Solana row, hand-authored SVG. An illustrative identifier, not an official project logo.
- `icons/wld.svg`: original sphere/grid glyph for the Worldcoin row, hand-authored SVG. An illustrative identifier, not an official project logo.
- `icons/mark-192.png`, `icons/mark-512.png`, `icons/apple-180.png`: browser rasterizations of `mark.svg`, with an opaque forest green background. The mark fits inside the central maskable icon safe area.
- Bottom navigation glyphs in `index.html`: three original inline SVG paths (overview, holdings, notes).
- Typography: the existing system font stack, including Apple SD Gothic Neo and Malgun Gothic. No external font requests.

These original assets may be used and modified with this application. The existing root PNG icons remain unchanged because Runway shares them. Screenshots and all visual QA fixtures use synthetic quantities, costs, prices and news. No screenshots are committed to the public repository.
